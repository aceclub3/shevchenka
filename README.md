# Проєкт Шевченка — сайт-галерея

**Живий сайт:** https://aceclub3.github.io/shevchenka/
**Хостинг:** GitHub Pages, безкоштовно. Локальна копія: `E:\Denys\shevchenka-site`

## Що всередині

| Файл / папка | Що це |
|---|---|
| `index.html` | Уся сторінка — HTML, CSS і JS в одному файлі |
| `data.js` | Список фото, розміри, секції — генерується скриптом |
| `img/f1`, `img/f2`, `img/dwg` | WebP: повні (2400 px) + мініатюри в підпапці `t/` (700 px) |
| `files/kreslennya.pdf` | Оригінальний PDF креслень для завантаження (66 МБ) |
| `process.mjs` | Скрипт збірки: стискає фото і рендерить сторінки PDF в картинки |
| `.nojekyll` | Каже GitHub не обробляти сайт Jekyll-ом. Не видаляти |

Оригінали дизайнера лежать окремо і не змінювались: `E:\Denys\Проект Шевченка`.

## Перегляд зображень

Відкрите зображення має власний зум — браузерний навмисно вимкнено (`touch-action:none`),
інакше жест масштабування зчитувався б як свайп і перекидав на наступний аркуш.

| Дія | Телефон | Компʼютер |
|---|---|---|
| Наблизити | два пальці або подвійний тап | колесо миші або подвійний клік |
| Рухати збільшене | палець по зображенню | перетягнути мишею |
| Гортати | свайп (працює лише при 100%) | стрілки ‹ › або клавіші ←/→ |
| Повернути 100% | кнопка з відсотками у шапці | та сама кнопка |
| Закрити | тап по фону, ✕ або «назад» | ✕ або Esc |

Гортання свідомо заблоковане при збільшенні — інакше рух пальцем по кресленню
перемикав би аркуш. Перехід на інший аркуш завжди скидає масштаб на 100%.

## Як оновити (додати чи замінити фото)

1. Покласти нові файли в оригінальну папку `E:\Denys\Проект Шевченка\візуалізації 1 поверх`
   (чи `візуалізації 2 поверх`), або замінити `Креслення.pdf`.
2. Перезібрати:

```powershell
cd E:\Denys\shevchenka-site
npm install          # тільки перший раз
node process.mjs
```

3. Викласти:

```powershell
git add -A
git commit -m "оновлення фото"
git push
```

Через 1–2 хвилини GitHub Pages опублікує зміни за тим самим посиланням.

## Що варто знати

- Ліміти GitHub Pages: 1 ГБ на сайт, 100 ГБ трафіку на місяць. Зараз сайт важить ~98 МБ — запас великий.
- Сайт публічний: хто має посилання, той бачить. Пошуковики його самі не знайдуть (на нього ніхто не посилається), але це не приватність.
- Прибрати сайт: вимкнути Pages у налаштуваннях репозиторію або `gh repo delete aceclub3/shevchenka`.
- Фото стискаються у WebP 2400 px — цього достатньо для перегляду на будь-якому екрані.
  Повний друкарський розмір завжди лишається в оригіналах і в PDF.
