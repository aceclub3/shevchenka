# Проєкт Шевченка — сайт-галерея

**Живий сайт:** https://aceclub3.github.io/shevchenka/
**Хостинг:** GitHub Pages, безкоштовно. Локальна копія: `E:\Denys\shevchenka-site`

Дворівнева квартира 160,5 м² (106,4 + 54,1): три спальні, три санвузли,
відкрита кухня-їдальня-вітальня з другим світлом.

## Структура сайту

Три вкладки над однією спільною бібліотекою зображень:

- **Кімнати** — 69 візуалізацій, розкладених по 18 приміщеннях двох поверхів, з фільтром.
- **Меблі** — 19 предметів індивідуального виготовлення. У кожного картка: креслення
  з розмірами й матеріалом плюс візуалізації, де цей предмет видно.
- **Креслення** — 14 планів (обмірні, меблювання, перепланування, сантехніка, стеля,
  освітлення, підлога) + 19 ескізів меблів + повний PDF на завантаження.

**Одне фото живе в одному екземплярі.** Кімната і предмет меблів лише посилаються
на нього за ключем на кшталт `f1/020`. Тому одна візуалізація може бути одночасно
в «Кухні» й у картці кухонного острова, не займаючи місця двічі й не розсинхронізовуючись.

## Файли

| Файл / папка | Що це |
|---|---|
| `index.html` | Уся сторінка — HTML, CSS і JS в одному файлі |

Оригінали дизайнера лежать окремо і не змінюються: `E:\Denys\Проект Шевченка`.

## Про якість зображень

Мініатюри ріжуться **по ширині**, а не по довгій стороні — сітка розкладає плитки
саме за шириною. Раніше портретне фото обмежувалось 700 px по висоті й давало лише
462 px ширини, через що на екрані з DPR 3 розтягувалось у 2,35 раза й виглядало
розмитим. Тепер кожне фото має чотири ширини, і браузер через `srcset` бере рівно ту,
що потрібна цьому екрану.

Вартість перегляду всієї галереї з 69 фото: **близько 700 КБ** на телефоні
(0,2 МБ на звичайному ноутбуці). Повний файл підвантажується лише коли фото відкривають.

Якщо міняєш кількість колонок у сітці (`.grid{columns:N}`) — **обовʼязково онови
`GRID_SIZES` у скрипті сторінки**, інакше браузер обиратиме неправильний розмір.

## Перегляд зображень

Масштабування **самої сторінки** вимкнено (`user-scalable=no` + `touch-action:pan-x pan-y`
на `html` + гасіння `gesturestart` для Safari на iPhone, який ігнорує перше й друге).
Причина: випадковий жест по мініатюрі збільшував увесь сайт і повернути 100% було майже
неможливо. Гортання сторінки при цьому працює як завжди.

Масштабуються тільки самі зображення — власним зумом усередині перегляду
(`.lb{touch-action:none}`, жести рахує скрипт).

| Дія | Телефон | Компʼютер |
|---|---|---|
| Наблизити | два пальці або подвійний тап | колесо миші або подвійний клік |
| Рухати збільшене | палець по зображенню | перетягнути мишею |
| Гортати | свайп (лише при 100%) | стрілки ‹ › або клавіші ←/→ |
| Повернути 100% | кнопка з відсотками у шапці | та сама кнопка |
| Закрити | тап по фону, ✕ або «назад» | ✕ або Esc |

## Як оновити

**Нові або замінені фото:** покласти в оригінальну папку, потім

```powershell
cd E:\Denys\shevchenka-site
npm install          # тільки перший раз
node process.mjs
git add -A; git commit -m "оновлення фото"; git push
```

**Виправити кімнату фото або звʼязок меблів із візуалізаціями:** відредагувати
`catalog.js` руками й запушити. Перезбірка зображень для цього не потрібна.

Прив'язки «креслення меблів → візуалізації» складені автоматично за кімнатою
й типом предмета, тож можуть містити неточності — це саме те, що варто вичитати.

## Що варто знати

- Ліміти GitHub Pages: 1 ГБ на сайт, 100 ГБ трафіку на місяць. Зараз сайт важить ~120 МБ.
- Сайт публічний: хто має посилання, той бачить. Пошуковики його самі не знайдуть,
  але це не приватність.
- Прибрати сайт: вимкнути Pages у налаштуваннях репозиторію або `gh repo delete aceclub3/shevchenka`.
